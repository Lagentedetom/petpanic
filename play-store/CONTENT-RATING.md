# Clasificación de contenido (IARC) — borrador de respuestas

> Play Console → Política → Clasificaciones de contenido. Cuestionario IARC.
> Categoría sugerida de la app: **Utilidad / Comunicación / Social** (no es juego).

| Pregunta del cuestionario | Respuesta |
|---|---|
| ¿Es una app de juego? | No |
| Violencia (real o ficticia) | No |
| Contenido sexual / desnudez | No |
| Lenguaje soez | No |
| Sustancias controladas (drogas/alcohol/tabaco) | No |
| Apuestas / juego con dinero real | No |
| Miedo / terror | No |
| **¿Los usuarios pueden interactuar o comunicarse entre sí?** | **Sí** (red de amigos, avisos a otros usuarios) |
| **¿Comparte la ubicación del usuario con otros usuarios?** | **Sí** (al lanzar un aviso, para la búsqueda) |
| ¿Permite compras digitales? | **Sí** (suscripción de pago "PetPanic Social" vía Stripe) |
| ¿Contenido generado por usuarios sin moderar? | Sí (fotos/datos de mascotas, perfiles) — declarar |

**Resultado esperado:** apta para todos los públicos (PEGI 3 / Everyone), con avisos por
"compartir ubicación" e "interacción entre usuarios". Verifica el resultado que devuelva IARC.
